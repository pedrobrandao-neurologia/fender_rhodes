Como tocar o Suitcase 73

No toque (celular e tablet)

  • Toque mais perto da borda de baixo da tecla para notas mais fortes (sensibilidade de dinâmica).
  • Deslize o dedo pelas teclas para fazer glissando.
  • Use vários dedos ao mesmo tempo para tocar acordes.

No teclado do computador

  • A–; tocam as notas (fileira de cima = teclas pretas), como um teclado de piano.
  • Z / X descem e sobem uma oitava.
  • Espaço funciona como pedal de sustain: segure para sustentar, solte para abafar.

Controles

  • Presets ajustam todos os controles de uma vez — experimente cada um!
  • Vibrato é o balanço estéreo entre os alto-falantes do gabinete Suitcase (use fones!).
  • Timbre (bark) vai do som suave e escuro ao ataque metálico agressivo.
  • ● Rec grava o que você toca; ao parar, baixa o arquivo de áudio.
  • Suas configurações são salvas automaticamente no navegador.

MIDI

Conecte um teclado MIDI (USB ou Bluetooth) e toque com dinâmica real — a luz MIDI acende quando um dispositivo é detectado. O pedal de sustain do teclado também funciona. Disponível no Chrome e Edge.

FenderRhodes

Suitcase Seventy Three — o piano elétrico das sessões de Get Back (1969). Toque mais perto da borda inferior da tecla para notas mais fortes. O vibrato estéreo balança o som entre os dois alto-falantes, como no gabinete original. Use fones ou caixas estéreo para o efeito completo. No computador: teclas A–; tocam notas, Z/X mudam a oitava e Espaço é o pedal de sustain.
